# Salvador Sierra — Portafolio de Arte

Sitio web oficial del pintor y artista visual Salvador Sierra.

**Live:** https://salvadorsierra.com.mx

## Estructura

```
├── index.html          — Página principal (español)
├── en/
│   └── index.html      — Página principal (inglés)
├── css/
│   └── styles.css      — Estilos globales
├── js/
│   └── main.js         — Lógica del sitio
├── images/
│   └── obras/          — Fotos de obras (WebP optimizado)
└── assets/
    └── fonts/          — Tipografía
```

## Tecnología

- HTML / CSS / JavaScript (vanilla)
- WebP para imágenes optimizadas
- Cloudflare Pages para hosting
- Bilingüe: ES / EN

## Fase

**Phase 1** — Sitio estático, portfolio visual, contacto.
**Phase 2** — E-commerce vía Shopify (futuro).
